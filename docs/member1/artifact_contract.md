## 1. Overview and Storage Convention

All production tables generated by Member 1 are stored in Apache Parquet format under:
`artifacts/member1/analytics/tables/<table_name>`

Figures (matplotlib PNGs and interactive Plotly HTML) are stored under:
`artifacts/member1/analytics/figures/<figure_name>`

Metadata and metrics are emitted as machine-readable JSON:
- `artifacts/member1/analytics/phase3_manifest.json`: Full inventory of generated tables, figures, bounding boxes, and data takeaways.
- `artifacts/member1/analytics/phase3_metrics.json`: Exact numeric validation tallies, coverage ratios, KMeans ablation scores, and DBSCAN sensitivity metrics.

> **Note on Version Control:** In accordance with repository rules (`AGENTS.md`), full artifact directories are gitignored. For team members without access to the raw 100k Parquet or local PySpark infrastructure, small sanitized reference fixtures are maintained in `tests/fixtures/member1/`.

## 2. General Data Semantics & Quality Guarantees

1. **Reporting Semantics:** All complaint counts represent *reported demand volume*, never per-capita defect rates, municipal response failure, or objective neighbourhood hazard.
2. **Deterministic Aggregation:** Every table is generated via deterministic PySpark grouping with explicit tie-breaking order.
3. **Null Transparency:** Records with unassigned or unrecognised borough, ZIP code, or complaint categories are preserved explicitly as `"UNKNOWN"` or `null`. Unknown values are never silently redistributed.
4. **Geographic Scoping:**
   - NYC Bounding Box: Latitude `[40.49, 40.92]`, Longitude `[-74.26, -73.70]`.
   - Spatial tables (`spatial_hotspots`, `spatial_grid_cells`, `cluster_summary`) strictly filter for valid coordinates within this box.
   - Non-spatial tables (`complaints_by_borough`, `complaints_by_category`, `complaints_daily`, etc.) retain all 100,000 records regardless of coordinate validity.
5. **Resolution Hours:** Calculated strictly for resolved complaints (`closed_at >= created_at`). Unresolved rows (`unresolved` flag) carry `null` duration; duration is never imputed as zero. Genuine zero-duration resolutions (`created_at == closed_at`) are preserved.
6. **Timezone:** Wall-clock local NYC time without offset.
